# Trade-calculator

Description:
This code is for traders looking to know if their risk parameters offer a favorable trade.

How to execute and what it does: 
1. It will request from you the pair traded, the entry price, the stop loss price and the take profit price.
2. It will calculate the trades risk to reward ratio.
